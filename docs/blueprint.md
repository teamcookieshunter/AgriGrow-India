# **App Name**: AgriGrow India

## Core Features:

- Multilingual User Login: Secure user authentication via phone number with language selection.
- AI Farming Assistant: AI-powered tool providing project guidance and advice, photo-based crop health analysis.
- Marketplace Integration: Real-time market pricing with buyer connections and digital invoicing.
- Government Scheme Updates: Notifications, eligibility checks and application guides for various agricultural schemes.
- Real-time Weather Alerts: Weather alerts and smart suggestions based on weather patterns.
- Community Forum: Forum for knowledge sharing and peer support. Allows users to connect and assist each other
- Emotional Support Chatbot: Chatbot that provides emotional support and guidance, helping farmers to manage stress.

## Style Guidelines:

- Primary color: Fresh Green (#60A917) to evoke growth, nature, and a positive connection to agriculture.
- Background color: Light Beige (#F5F5DC) to create a warm, accessible, and user-friendly interface, with brightness appropriate to a light color scheme. 
- Accent color: Earthy Brown (#A0522D) to enhance the natural, grounded feel, providing contrast and visual interest.
- Body and headline font: 'PT Sans', a humanist sans-serif font that balances a modern look with approachability, for readability across varying tech literacy levels.
- Simple and clear icons to aid navigation, accessible even to users with minimal technical expertise.
- Intuitive layout with large buttons, clear sections, and simplified data input to reduce complexity.
- Gentle animations when loading new information, providing non-jarring feedback and enhanced UX.
